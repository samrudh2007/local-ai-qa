\# Local AI Q\&A



A simple local AI chatbot built with Python, Ollama, and Gemma 3 1B.



\## Current Features



\- Runs a local Gemma 3 1B model through Ollama

\- Accepts questions from the terminal

\- Generates AI responses locally

\- Supports repeated conversation until `exit` is entered

\- Uses a system instruction to keep responses concise



\## Requirements



\- Python 3.11+

\- Ollama

\- Gemma 3 1B
